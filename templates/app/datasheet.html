Datasheet

Composition, collection, and intended use of the OneCare Loop synthetic dataset.

Motivation

Built to demonstrate the full care loop — screening, referral, hospital disposition — on realistic Nigerian hypertension data, without using real patient records. The dataset is generated, not collected. This page documents exactly what is in it.

Composition

Age bandCategorical18-29 (10%), 30-39 (18%), 40-49 (28%), 50-59 (24%), 60+ (20%)

Collection process

No real data was collected. The dataset was generated by a seeded script (seed=20251115) that samples from the distributions above. It ships in the repository and can be regenerated byte-for-byte. Any deviation in a judge's run means our generator drifted — that would be a bug we want to know about.

Preprocessing

  • Dates are relative to 2025-11-15, not wall-clock — so the dataset ages gracefully.
  • All identifiers are UUIDs generated fresh on each seed.
  • Phone numbers are format-valid but non-routable: +23480 0000 XXXX.
  • Names are not generated. Patients are referenced only by UUID.

Uses

Intended
  • Demonstrating the state machine and dashboard
  • Training the drop-off risk score
  • Reproducibility of the demo
  • Integration-testing FHIR exports
Not intended
  • Training any clinical model
  • Benchmarking against real Nigerian cohorts
  • Publication as epidemiological evidence
  • Any use in a live care setting

Distribution & maintenance

The dataset is distributed under the same license as the code (MIT). It is maintained alongside the code: any change to the distributions above requires a version bump on the generator and an entry in CHANGELOG. Regeneration is a single command (python seed.py) and produces a checksum-verifiable output.
